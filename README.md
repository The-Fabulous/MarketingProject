# MarketingProject

Две страницы:

- http://localhost:3000 — микрофон → текст.
- http://localhost:3000/check — **проверка аудио/видео по правилам**: загрузите файл, напишите правила своими словами
  (мат, сексуализация, оскорбления…), получите список нарушений с таймкодами. Клик по таймкоду перематывает плеер.
  Можно скачать отчёт в .txt.

Всё бесплатно: речь распознаётся локально (faster-whisper на вашем компьютере), правила проверяет Gemma4 через Alem.

## Быстрый старт (Windows)

1. Установите [Node.js 22+](https://nodejs.org) и [Python 3.12](https://www.python.org/downloads/) (отметьте «Add python.exe to PATH»).
2. Дважды кликните **`start.bat`**. При первом запуске он:
   - создаст `.env` и откроет его в Блокноте — впишите свой ключ Alem в `OPENAI_API_KEY`, сохраните и закройте;
   - установит распознавание речи и скачает модель (~1.6 ГБ, ещё ~1 ГБ библиотек при видеокарте NVIDIA) — 5–15 минут;
   - запустит два окна («Whisper» и «Сайт») и откроет http://localhost:3000/check в Chrome.
3. Дальше — просто `start.bat`. Чтобы остановить, закройте оба окна.

Ключ хранится только в `.env` на вашем компьютере и в Git не попадает.

## Первый запуск вручную

1. Установите Node.js 22+ и Python 3.10–3.12.
2. Установите распознавание речи (один раз, ~1.5 ГБ с библиотеками для видеокарт NVIDIA):
   ```
   python -m venv .venv
   .venv\Scripts\python -m pip install faster-whisper "av<16" nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
   ```
   Без видеокарты NVIDIA пакеты `nvidia-*` не нужны — будет работать на процессоре (медленнее).
3. Скопируйте `.env.example` в `.env` и вставьте ключ Alem в `OPENAI_API_KEY`.

## Запуск — два окна терминала

```
npm run stt     # распознавание речи на http://127.0.0.1:8001 (при первом запуске скачает модель ~1.6 ГБ)
npm start       # сайт на http://localhost:3000
```

## Как работает проверка

1. Браузер сам извлекает звук из файла (видео тоже), переводит в 16 кГц mono и режет на фрагменты по 60 с с перекрытием 4 с.
   Тишина пропускается.
2. Локальный Whisper (`stt_server.py`, модель `large-v3-turbo`) превращает фрагмент в фразы со временем начала.
3. Пронумерованные фразы и правила уходят в Gemma4 текстом. Модель возвращает номер фразы, правило, цитату и объяснение.
   Таймкод нарушения — начало фразы.

Поддерживаемые форматы — то, что декодирует браузер (Chrome/Edge): MP3, WAV, M4A, OGG, MP4, WEBM.
Для MKV/AVI сначала извлеките звук.

## Настройки

- `WHISPER_MODEL` (для `npm run stt`): `large-v3-turbo` по умолчанию; на слабом компьютере без видеокарты — `small` или `medium`.
- `WHISPER_DEVICE`: `auto` | `cuda` | `cpu`.
- `STT_LANGUAGE=ru` фиксирует язык; пусто — автоопределение (например, для казахского).
- Вместо локального Whisper можно указать любой OpenAI-совместимый `/audio/transcriptions` в `STT_BASE_URL`, `STT_API_KEY`, `STT_MODEL`.

Gemma4 на Alem аудио напрямую не принимает, поэтому речь распознаётся отдельно.
Ключи доступны только серверу; `.env` исключён из Git. Оба сервера слушают только localhost; записи на диске не сохраняются.
