# MarketingProject

Простая страница: микрофон → WAV (16 кГц, mono PCM) → сервер → Gemma4 → текст.

1. Установите Node.js 22 или новее.
2. Вставьте ключ в `OPENAI_API_KEY` в `.env`.
3. Из папки проекта выполните `npm start`.
4. Откройте http://localhost:3000 и разрешите микрофон.

Зависимости устанавливать не нужно. После изменения `.env` перезапустите сервер.
Ключ доступен только серверу; `.env` исключён из Git. Сервер раздаёт только два публичных файла и слушает localhost.

Используется то же подключение, что в Classifi: https://llm.alem.ai/v1/chat/completions, модель gemma4.
Документация провайдера: https://doc.alem.ai/services/gemma4.html.
Аудио отправляется как OpenAI-совместимый `input_audio` (WAV). Поддержка аудио на конкретном развёртывании Alem не подтверждена: без ключа реальную расшифровку проверить нельзя. Если API отклоняет аудио, потребуется аудиосовместимая модель/endpoint или отдельный сервис распознавания речи. Текст не подменяется распознаванием браузера.

Записи и расшифровки не сохраняются на диске. Предыдущий текст остаётся при ошибке нового запроса.
Для размещения в интернете нужен сервер Node.js, HTTPS и контроль доступа; статического хостинга недостаточно.
